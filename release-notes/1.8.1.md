Choose a game's cover and background yourself, with a search by name; a tidier game menu; DirectX 12 games that need feature level 12_0; sound for games that ask for spatial audio; and a library folder FTP can open.

### Install

From PC5 1.8.0: **Settings › Updates › Update now**, or **Update now** when PC5 asks as it opens. PC5 restarts by itself when the update is installed.

By hand:

1. Download `PPSA11018.zip` and unzip it.
2. Replace the `PPSA11018` folder on the console with the new one, the way you add homebrew. Your games, saves and settings stay where they are.
3. Start PC5. Options › About PC5 shows 1.8.1.

Updating from PC5 1.7.0: it closes at the end of the update instead of restarting, and the console then shows error CE-108255-1. The update is installed all the same: open PC5 again.

### What's new

- **Choose a cover or background**: **△ › Appearance › Cover** or **Background** shows the one the game has, then what PC5 finds for its names. **L1** / **R1** go through them, **△** opens the PS5's keyboard to search for another name, and **✕** uses the one shown. A background can also be **None**: PC5's own backdrop. See [Changing a cover or background](https://github.com/bornaradusin/PC5/wiki/Covers#changing-a-cover-or-background).
- **A tidier game menu**: **Play** and **Controller**, then three groups.
  - **Graphics**: frame generation, resolution, aspect ratio and memory.
  - **Appearance**: cover, background and home screen tile.
  - **Manage**: change program, update and uninstall.
  - In the game menu and in Settings, a row says what it does only while it is chosen. See [The game menu](https://github.com/bornaradusin/PC5/wiki/Playing-games#the-game-menu).
- **DirectX 12 feature level 12_0**: Direct3D 12 games that ask for it, such as those made with Unreal Engine 5, no longer stop at their DirectX 12 check. Games installed earlier get this the next time they start. Whether a game then runs all the way is only known by trying it.
- **Spatial audio**: games whose sound engine asks Windows for spatial audio (7.1.4) now have sound. PC5's sound takes up to 18 channels and folds them down to the console's output.
- **The library's folder**: on a new console, PC5 made `/data/prospero-win` and its `logs` folder open only to itself, which kept FTP and file managers out of them on some setups. They are now made like PC5's other folders, and a folder PC5 made that way before is opened up when PC5 starts.
- **A more detailed log for one game**: a `winedebug.txt` in the game's notes folder sets what Wine writes to its log, for when an issue asks for more detail. See [A more detailed log, for one game](https://github.com/bornaradusin/PC5/wiki/Reporting-a-problem#a-more-detailed-log-for-one-game).
- **Startup sounds**: the PC5 sound is gone. **cheap chinese speaker** is the new default, and players who had PC5's own sound get it.
- **Smaller download**: the sound modules from 1.8.0's XAudio2 fix no longer carry their debugging data.
- Everything in 1.8.0 is unchanged: updating a game from USB, keeping a game's saves when uninstalling it, game backgrounds, startup sounds, smoother movies, and PC5 restarting by itself after an update.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues), not in ProsperoStore's comments, and attach the game's zip from `/data/prospero-win/logs/` (`issue-…zip`, or the game's newest `log-…zip` when nothing crashed). △ on PC5's crash message opens the form for you. Say which PC5 version you use (Options › About PC5) and what happened. Without the log the cause can't be found. If an update from PC5 fails, the message says why; turn on **Settings › Keep all logs**, try again and attach PC5's own log.

### Not supported

Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher), anti-cheat, and games that need kernel drivers. .NET programs that mix .NET and C++ (C++/CLI). Recording or saving video from inside a game. Frame generation for DirectDraw games, games drawn without 3D, and HDR output. Changing a game's controller mode, resolution or aspect ratio while it runs. DRM protected. PC5 installed as a package (`.pkg`) can't update itself: it updates from a folder only.
